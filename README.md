# いろどり日语单词背诵面板

> 📖 在线使用：GitHub Pages 首页（`https://<用户名>.github.io/japanese-words-panel/`）

日本国际交流基金会（The Japan Foundation）免费教材《いろどり Japanese for Life in Japan》官方词汇表单词背诵工具。

- **入門 Starter（A1）** 1209 词 · 18 课
- **初級1 Elementary 1（A2）** 1015 词 · 18 课
- **初級2 Elementary 2（A2+）** 1572 词 · 18 课

共 **3796 条**（官方词表去重、按课分组）。

## 功能

- 三册总览与切换（54 课），点击打卡 ✓，进度实时统计
- 假名注音 + 罗马字（官方风格 けい→kee），🔤 按钮可开关
- 点日文词跳转沪江小D 日中词典查完整释义/发音/例句
- 搜索支持 日文 / 假名 / 罗马字 / 中文；词库没有的词提供 沪江小D / jisho / Weblio 跳转
- 🎴 自测模式（遮中文）、多用户独立进度

## 说明

- 词汇数据来自 [いろどり官方词汇表](https://www.irodori.jpf.go.jp/)（wordlist_all.xlsx，CC 版权免费教材）
- 中文释义由英文官方释义翻译而来
- 打卡进度保存在各自浏览器本地（localStorage）

仅供个人学习使用。教材版权归日本国际交流基金会所有。
